# ❤️ OURFLIX — Riddhi & Aditya

A Netflix-style anniversary website. Counting since **20 December 2025, 5:35 PM (IST)**.

## Open it
Double-click `index.html` (works offline; only the fancy fonts need internet).
To share it with Riddhi, drag this whole folder onto **https://app.netlify.com/drop** and send her the link.

## Want to change something? ✏️
Read **`edit.md`** — it explains step by step how to add your songs, the opening-curtain sound, your letters, photos and texts.

## Add your sounds 🎵
Put 5 MP3 files in `assets/audio/` with these exact names:

```
song-1.mp3   ← the Netflix-style intro (plays when the curtain opens)
song-2.mp3   song-3.mp3   song-4.mp3   song-5.mp3   ← your 4 songs
```

Song titles/artists are in `data.js` (section `songs`). Until a file is added the player shows "Song file not added yet".

## What's inside
```
index.html   – page structure
styles.css   – design
script.js    – timer, Yes/No game (4 rounds), modals, player
data.js      – all names, dates, photo links, texts, song titles, and the secret letter (EDIT 6)
assets/images/  – all photos (together.jpg is the couple photo)
assets/audio/   – drop song-1.mp3 (curtain intro sound) and song-2..5.mp3 (your songs) here
edit.md      – the editing guide
```

There are no customisation buttons on the website itself — the final site is exactly what's in these files.
